# خانه مدرن — Storefront Design Language

The shared vocabulary for the storefront's visual language. It exists so "make it more
colorful" or "make it live" resolve to one meaning rather than two.

## Language

**Showcase**:
The store's premium visual language: product qualities are shown, not labeled, and variation is
presented as real objects rather than counted tags.
_Avoid_: badge-driven UI, retail tags, generic e-commerce look

**Flame blue**:
The single chromatic accent. It marks activation and current state only and never exceeds a small
fraction of any screen.
_Avoid_: a second accent hue, warm metallics, decorative color

**Listing pulse**:
The result toolbar above a product listing: what the current view holds (count), what is narrowing
it (removable filter chips), and how it is ordered (quick sort).
_Avoid_: tool strip, filter bar, results header

**Live**:
Interactive feedback a shopper causes — hover, press, active filter, disclosure, state change.
_Avoid_: ambient loops, auto-rotating content, decorative animation
